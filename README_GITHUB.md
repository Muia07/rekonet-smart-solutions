## 🚀 Quick Start

### Prerequisites
- Node.js 14+ (for development server)
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/rekonet-systems.git

# Navigate to project directory
cd rekonet-systems

# Install dependencies (optional - for development)
npm install

# Start development server
npm start
```

### Development Server
```bash
# Start local server on port 3000
npm start

# Or use Python
python -m http.server 3000

# Or use PHP
php -S localhost:3000
```

## 🌐 Deployment

### Netlify (Recommended)
1. Connect your GitHub repository to Netlify
2. Set build command: `echo 'Static site'`
3. Set publish directory: `.` (root)
4. Deploy!

### Vercel
1. Import your GitHub repository
2. Framework preset: Other
3. Deploy!

### GitHub Pages
1. Go to repository Settings
2. Navigate to Pages section
3. Select source: Deploy from a branch
4. Choose branch: main
5. Save

### Manual Deployment
```bash
# Build for production
npm run build

# Upload to your web server
# All files in root directory are production-ready
```

## 🎨 Customization

### Colors
Update CSS custom properties in `src/css/rekonet.css`:
```css
:root {
  --primary: #0a2540;
  --accent: #00b4d8;
  --background: #ffffff;
  --foreground: #0a2540;
}
```

### Fonts
Update Google Fonts link in `index.html`:
```html
<link href="https://fonts.googleapis.com/css2?family=Your+Font:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
```
